# 鹈鹕骑车

一个用 Three.js 做的小品：一只鹈鹕骑着自行车，沿着循环的海边公路一直向前。长扁嘴、喉囊、S 形脖子和蹼足都在，车轮、脚踏和腿同步转动，脖子会跟着踏频轻轻点。

## 环境

需要 Node.js 18 及以上。

## 本地运行

```bash
npm install
npm run dev
```

浏览器打开终端里给出的本地地址（默认 `http://127.0.0.1:43123`）。

## 构建

```bash
npm run build
npm run preview
```

`npm run build` 会先做类型检查，再把页面打包到 `dist/`。

## 操作

- 拖拽：旋转相机
- 滚轮或双指：缩放
- 速度滑杆：改变骑行速度，车轮、脚踏和腿保持同步
- 暂停 / 继续，或按空格键

## 实现简记

场景用 Vite + TypeScript + Three.js 搭成。自行车和鹈鹕都由基础几何体拼出来。翅膀和腿用双骨 IK，分别够到握把和脚踏，所以踏频变了，蹼足还是踩在踏板上。海边的路、沙滩、海面、栈桥和海鸥分成几层往后滚动，走出画面后接到队列末尾，骑行可以一直循环。
